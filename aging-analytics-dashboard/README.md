# Thailand Elderly Health Situation Dashboard
แดชบอร์ดสถานการณ์สุขภาพผู้สูงอายุไทย (ปีงบประมาณ 2566 – 2569)
สถาบันเวชศาสตร์สมเด็จพระสังฆราชญาณสังวรเพื่อผู้สูงอายุ กรมการแพทย์ กระทรวงสาธารณสุข

---

## 🚀 วิธีการรันระบบ (How to Run)

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd aging-analytics-dashboard

# 2. ติดตั้ง Dependencies (ทำครั้งแรก)
npm install

# 3. เริ่มรัน Development Server
npm run dev

# 4. เปิดเบราว์เซอร์เข้าใช้งานที่
http://localhost:5173
```

## 📊 โครงสร้างข้อมูลและ 3 แท็บหลัก (Dashboard Architecture)

### แท็บที่ 1: การคัดกรองผู้สูงอายุ 9 ด้าน (Basic/Community Screen)
* **แหล่งข้อมูล:** HDC กระทรวงสาธารณสุข & Blue Book Application กรมอนามัย
* **เนื้อหา:** 
  * **การเฝ้าระวังพื้นที่เสี่ยง 77 จังหวัด:** ฮีทแมพและตารางเฝ้าระวังพื้นที่เสี่ยงสูง (Risk Hotspots) ราย 9 มิติสุขภาพตามแนวทาง WHO ICOPE
  * **ความชุกของกลุ่มเสี่ยง 9 มิติ:** สายตาเสี่ยงสูงสุด 14.9% (1.37M คน), ช่องปาก 11.9% (1.10M คน), การเคลื่อนไหว 8.9% (815k คน), ADL ติดบ้าน/ติดเตียง 6.2%, ได้ยิน 5.2%, สมองเสื่อม 5.1%, ปัสสาวะ 4.5%, โภชนาการ 4.1%, ซึมเศร้า 1.4%
  * **ระบบฟิลเตอร์และเจาะลึกพื้นที่เสี่ยง:** ปุ่มลัดเลือก 9 มิติ, ค้นหารายจังหวัด, กรองพื้นที่เสี่ยงสูงกว่าค่าเฉลี่ยประเทศ, สรุป 5 อันดับจังหวัด Hotspot สูงสุดรายมิติ

### แท็บที่ 2: สถิติสาเหตุการป่วยและสาเหตุการตาย
* **แหล่งข้อมูล:** HDC สป.สธ. (แฟ้ม OPD/IPD) และ กองยุทธศาสตร์และแผนงาน สป.สธ. / สำนักบริหารการทะเบียน กรมการปกครอง
* **เนื้อหา:** 
  * **10 อันดับโรคและปัญหาสุขภาพสำคัญ:** สรุปอัตราความชุกและลักษณะอาการสำคัญทางการแพทย์ในผู้สูงอายุพร้อมไอคอนเฉพาะโรค
  * **10 อันดับการป่วย OPD & IPD:** ชาร์ตเปรียบเทียบ Top 5 OPD visits vs IPD admissions และตาราง 10 อันดับแรก
  * **10 อันดับสาเหตุการตาย:** มะเร็งทุกชนิดอันดับ 1 (68,500 ราย/ปี), สโตรกอันดับ 2 (52,100 ราย/ปี), ปอดอักเสบอันดับ 3 (42,000 ราย/ปี) พร้อมแถบสีคู่เปรียบเทียบเพศชาย vs หญิง

### แท็บที่ 3: ข้อมูลคลินิกผู้สูงอายุ
* **แหล่งข้อมูล:** รายงานผลการประเมินมาตรฐานคลินิกผู้สูงอายุ กรมการแพทย์ กระทรวงสาธารณสุข
* **เนื้อหา:** 
  * สรุปผลการประเมินมาตรฐานคลินิกผู้สูงอายุในโรงพยาบาลเป้าหมาย 937 แห่ง ครอบคลุม 13 เขตสุขภาพ
  * จำแนก รพ. ตามระดับศักยภาพ: ระดับ A, S, M1, M2, F1, F2, F3
  * ผลการประเมิน: ผ่านเกณฑ์ดีเด่น (84 แห่ง), ดีมาก (237 แห่ง), ดี (345 แห่ง), ผ่านพื้นฐาน (147 แห่ง), ควรพัฒนา (5 แห่ง), ยังไม่ประเมิน (119 แห่ง)
  * แผนที่คลินิกประเทศไทย, แผงเจาะลึกรายจังหวัดและรายชื่อโรงพยาบาล, ชาร์ตผลประเมินรายเขต และตารางครบ 77 จังหวัด

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **Framework:** React 19 + TypeScript + Vite 6
* **Styling:** Tailwind CSS v3 + CSS Variables
* **Visualization:** Recharts v2 (Bar, Area, Line, Donut)
* **Icons:** Lucide React
* **Typography:** Google Fonts (Sarabun & Prompt)
* **Data Source:** Pre-processed Normalized JSON Models (256 KB)
