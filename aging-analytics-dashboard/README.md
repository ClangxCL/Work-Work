# Thailand Aging Health & Clinical Analytics Dashboard
ระบบสารสนเทศและแดชบอร์ดสถานการณ์และสุขภาพผู้สูงอายุไทย (ปีงบประมาณ 2566 – 2569)
สถาบันเวชศาสตร์สมเด็จพระสังฆราชญาณสังวรเพื่อผู้สูงอายุ กรมการแพทย์ กระทรวงสาธารณสุข

---

## 🚀 วิธีการรันระบบ (How to Run)

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd aging-analytics-dashboard

# 2. ติดตั้ง Dependencies (ทำครั้งแรก)
npm install

# 3. เริ่มรัน Development Server
npm run dev

# 4. เปิดเบราว์เซอร์เข้าใช้งานที่
http://localhost:5173
```

## 📊 โครงสร้างข้อมูลและ 4 แท็บหลัก (Dashboard Architecture)

### แท็บที่ 1: คลินิกผู้สูงอายุ (Geriatric Clinics)
* **แหล่งข้อมูล:** `geriatric_clinic_report.xlsx`
* **เนื้อหา:** 
  * สรุปผลการประเมินมาตรฐานคลินิกผู้สูงอายุ ปี 2567 รายเขตสุขภาพและราย 77 จังหวัด
  * จำแนก รพ. ตามระดับศักยภาพ: ระดับ A (43 แห่ง), S (55 แห่ง), M1 (38 แห่ง), M2 (96 แห่ง), F1 (101 แห่ง), F2 (505 แห่ง), F3 (75 แห่ง) รวม 913+ แห่ง
  * ผลการประเมิน: ผ่านเกณฑ์ดีเด่น (84 แห่ง), ดีมาก (237 แห่ง), ดี (345 แห่ง), ผ่านพื้นฐาน (147 แห่ง), ควรพัฒนา (5 แห่ง), ยังไม่ประเมิน (119 แห่ง)
  * ตารางสืบค้นรายจังหวัด ค้นหาได้ทันที พร้อมแถบแสดงเปอร์เซ็นต์ความครอบคลุม

### แท็บที่ 2: ข้อมูลประชากรสูงวัย (Demographic Trends 2566–2569)
* **แหล่งข้อมูล:** `ข้อมูลประชากรผู้สูงอายุ_60ปีขึ้นไป_2566-2569_รายเขต_รายจังหวัด.xlsx`
* **เนื้อหา:** 
  * แนวโน้มประชากรสูงอายุ 4 ปี (2566: 9.58M ➔ 2569: 10.98M คน, เพิ่มขึ้น +1.38M คน คิดเป็น +14.49%)
  * สัดส่วนผู้สูงอายุ (% Aging Ratio) เพิ่มจาก 21.83% สู่ 25.00% (เข้าสู่ Super-Aged Society)
  * พีระมิดประชากรแยกตามช่วงอายุย่อยทุกช่วง 5 ปี (60-64 จนถึง 100+ ปี) แยกเพศชาย vs หญิง
  * ตารางเปรียบเทียบสถิติและอัตราเติบโตรายเขตสุขภาพ 1–12

### แท็บที่ 3: ข้อมูลสุขภาพและการคัดกรอง (Screening & Care Tools)
* **แหล่งข้อมูล:** `1. hdc_elderly_screening_9domains.xlsx` และ `2. geriatric_data_report_2567-2569.xlsx`
* **เนื้อหา:** 
  * **HDC คัดกรอง 9 ด้าน:** เป้าหมาย 10.98M คน คัดกรองครบ 9 ด้านแล้ว 8.85M คน (80.59% ทะลุเป้าหมาย)
  * ความชุกของกลุ่มเสี่ยง 9 มิติ: สายตาเสี่ยงสูงสุด 14.9% (1.37M คน), ช่องปาก 11.9% (1.10M คน), การเคลื่อนไหว 8.9% (815k คน), ADL 6.2%, ได้ยิน 5.2%, สมองเสื่อม 5.1%, ปัสสาวะ 4.5%, โภชนาการ 4.1%, ซึมเศร้า 1.4%
  * **DMS Care Tools:** กลุ่มเสี่ยงหกล้ม (Falls), การส่งต่อรักษา, และการจัดทำ Care Plan รายบุคคลต่อเนื่อง รวมถึงกลุ่มเสี่ยงสมองเสื่อม (AMT)

### แท็บที่ 4: โรคเรื้อรังและสาเหตุการเสียชีวิต (Morbidity & Mortality)
* **แหล่งข้อมูล:** `3. สถิติผู้สูงอายุ_NCDs_2566-2569.xlsx`, `4. สถิติสาเหตุการป่วย_10อันดับแรก_2566-2569.xlsx` และ `5. สถิติสาเหตุการตายในผู้สูงอายุ.xlsx`
* **เนื้อหา:** 
  * **โรค NCDs 2566–2569:** ผู้สูงอายุป่วย NCDs รวม 8.90 ล้านคน (~75% ของผู้สูงอายุไทย) โดยความดันโลหิตสูงครองอันดับ 1 (5.72M คน) เบาหวานอันดับ 2 (2.81M คน) โรคไตเรื้อรัง CKD (9.7 แสนคน) สโตรก (3.25 แสนคน)
  * **10 อันดับการป่วย OPD & IPD:** ความดันและเบาหวานครองการตรวจผู้ป่วยนอก (>38 ล้านครั้ง) ขณะที่ปอดบวมและต้อกระจกครองการนอนโรงพยาบาล
  * **10 อันดับสาเหตุการตาย:** มะเร็งทุกชนิดอันดับ 1 (68,500 ราย/ปี), สโตรกอันดับ 2 (52,100 ราย/ปี), ปอดอักเสบอันดับ 3 (42,000 ราย/ปี) พร้อมวิเคราะห์ความแตกต่างระหว่างเพศชาย vs หญิง

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **Framework:** React 19 + TypeScript + Vite 6
* **Styling:** Tailwind CSS v3 + CSS Variables
* **Visualization:** Recharts v2 (Bar, Area, Line, Donut)
* **Icons:** Lucide React
* **Typography:** Google Fonts (Sarabun & Prompt)
* **Data Source:** Pre-processed Normalized JSON Models (256 KB)
